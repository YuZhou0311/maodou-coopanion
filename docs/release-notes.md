本轮调整耳根同源材质、头耳共同外缘、侧耳 Bézier 流线与大角度后垂，并改进近远四肢层级、交替支撑和落地转角。完整实现说明与适用范围见 [v1.3.2 版本记录](releases/v1.3.2.md)，发布结果与源码哈希见 [当前验收入口](qa/acceptance.md)。

## v1.3.1 · 历史记录

以下内容记录 v1.3.1 当时的修改与检查，不作为 v1.3.2 的验收结论。原始证据保留于 [v1.3.1 目录](qa/v1.3.1/)。

本次继续使用已选的第一版正面形体，只缩短头部冠顶至下颊的高度约 3.5%，保持下颊锚点、五官注册和宽耳根连接。没有把头重新简化为椭圆。

走路和跑步将原生左右腿位置接入脚部横移与抬起，小爪按步态相位摆动，身体重心和耳朵一起响应。最终追加抬耳幅度使近侧爪更容易看见；起步与停止经过既有连续阻尼。新增整耳抬起及外展，耳尖保留延迟，耳朵招手、扑腾、伸展和庆祝都能出现大幅动态。

身体内部旧手臂轮廓由图像模型在生成原图中清理。外耳根多余的粉色折痕阴影也由图像模型清理；头耳接缝的 UV 取样与近侧遮挡覆盖随形变同步，侧转仍保留近耳对面部的前向遮挡。

拖拽修复包含角色适配器和独立旧宿主补丁：转发真实按键与指针标识，补齐窗口释放、失去 capture、失焦和隐藏取消，保留正常甩出。旧宿主未发送释放状态时，角色 ZIP 自身不能还原缺失信息，因此需同时应用 [宿主补丁](../host-fix/README.md)。这份工程不会自动修改现有 Coopanion 安装。

v1.3.1 当时的验收包含 159 个转向观测、两性格左右走跑的 960 帧与停步 192 帧、两组指针路径各 7/7、原生导入 10/10、综合与离线检查 24/24。源码及结果范围分别保留在该版的 [综合摘要](qa/v1.3.1/release-final/summary.json)、[走跑摘要](qa/v1.3.1/gait-final/summary.json)、[指针摘要](qa/v1.3.1/pointer/summary.json) 和 [原生导入记录](qa/v1.3.1/native-import.json)，不把这些数字移用于后续版本。
