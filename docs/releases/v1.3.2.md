# v1.3.2 · 耳根衔接、侧耳流线与走跑步态

本轮围绕耳根与头部的色差接缝、侧转时耳部轮廓起伏，以及走跑中手脚的显示与支撑关系调整。角色继续使用选定正面稿的形体、已有绘画图集和 Coopanion 原生动作输入。

本文记录实现内容与适用范围。发布包对应的最终验收、实际运行画面和源码哈希见 [验收入口](../qa/acceptance.md)；安装文件与 SHA-256 见 [dist/README.md](../../dist/README.md)。

## 修改内容

### 耳根与头部使用同源材质

耳根现在按当前头部网格的位置，采样同一方向的头部绘画颜色。转向时，头部与耳根使用相同的两张方向材质及混合进度；沿耳朵长度逐渐恢复原耳材质，保留内耳和耳尖配色。

这项调整仅改变颜色。耳部几何、透明度、前向遮挡和裁剪仍由原来的网格与覆盖关系决定，前后耳层共享同一组材质参数。材质源采到透明像素时回退到原耳颜色，防止透明区域混入黑色。角色的外描边仍从整个人物的合成透明轮廓生成。

### 侧耳轮廓与大角度后垂

侧向耳中心线改用三次 Bézier 曲线，截面宽度由圆润耳根、渐宽中段和耳尖组成，轮廓不再跟随切件边缘的小幅起伏。

中间转向时，耳肩与头部被耳根覆盖的分支共用一条外缘过渡曲线。两块网格在上侧连接的短区间一起修整，头部的局部修正分散到相应网格行，使旧的凸起和凹口共同收进连续外缘。这项肩部修正随转向渐入、渐出，作用范围不延伸到脸颊、下巴或耳尖；正面与约 45°、75° 关键姿态不受这一步局部修正。

左右两侧肩部形状都更新后，再按修正后的头部网格投影耳根材质，使连接两侧的颜色对应同一条最终外缘。相关中间角度与强耳动作的实际记录见验收入口列出的 `shoulder-plus21-verified/`、`shoulder-minus21-verified/`；实现说明不代替这些记录的具体检查范围。

约 75° 侧转时，近耳中心线向后下方延伸，改变此前近耳在脸前形成竖直条块的走势。整耳抬起、展开、局部卷曲和耳尖延迟继续使用同一套耳网格；抬耳通过中心线分段旋转及截面旋转完成。

### 手臂、双脚与躯干的前后关系

近侧手臂和脚部增加位于躯干前方的覆盖层，远侧肢体保持在后。覆盖层共享原肢体的几何与采样，在躯干范围内表达前后关系；手臂根部同步使用躯干颜色衔接。

随着角色转向，两脚的横向投影间距收拢，使摆动脚能够越过支撑脚。近侧脚的层级由朝向决定，在两脚交叉时保持稳定，不随每半个步态周期交换前后。

### 单脚支撑、交错摆动与连续落地

走跑从宿主 `legsScreen` 的左右端点恢复相位和幅度，继续跟随宿主的方向、加速和停止过程。左右脚采用相差半个周期的支撑与摆动轨迹，并保留短暂双脚支撑。

支撑段的脚底抬升量为零；摆动段使用与支撑段连续连接的水平曲线，以及起落速度归零的抬脚曲线。进入稳定走跑后，脚部直接跟随这条连续轨迹，减少重复平滑造成的落地后悬浮；起步与停止仍有过渡。脚部转角随抬起高度连续收回到落地角度，避免高度阈值造成的突然转动。

摆臂相位随左右脚分别变化，耳朵的抬起、展开与耳尖响应跟随同一原生步态。脚、手臂和耳部使用各自的响应速度，形成有先后的动作关系。

## 接入与适用范围

| 项目 | 范围 |
| --- | --- |
| 运行格式 | Coopanion `manifest: 2 / api: 2` 的绘画分层网格角色 |
| 安装与升级 | 导入 `Maodou-Coopanion-v1.3.2.zip`；角色 ID 仍为 `maodou-shiny`，已有同 ID 版本时按宿主导入器提示替换 |
| 离线预览 | `Maodou-Offline-Preview-v1.3.2.html` 可保存后双击打开，内嵌角色资源与字体 |
| 转向 | 约 −75° 至 +75° 的左右侧转；方向形体属于制作推定，未扩展为完整 360° 模型 |
| 表情与动作 | 25 个表情、28 个动作，共 53 个词；保留「温柔」与「活泼」两种性格 |
| 步态 | 从宿主输入驱动的模型空间支撑与摆动；未实现世界坐标锁足或环境地形适配 |
| 口型与声音 | 响应宿主说话脉冲；声音表为空，未增加音频对嘴或录音 |
| Cubism | 不包含 `moc3`、`model3.json` 或 Cubism Editor 工程 |

完整安装、源码运行与构建步骤见 [README](../../README.md)。

### 旧宿主的指针释放补丁

本包保留角色端的指针恢复，以及 [host-fix/pointer-release.patch](../../host-fix/pointer-release.patch)。若旧宿主在丢失释放事件后没有转发 `buttons=0` 或取消消息，只更新角色 ZIP 不能补齐宿主路径；需要同时按 [宿主补丁说明](../../host-fix/README.md) 应用补丁并更新宿主。

补丁适用基线、合并方式和检查命令均在补丁说明中记录。这个独立角色仓库的更新不会自动修改已经安装的 Coopanion。

材质接口、动画与宿主适配的代码契约检查，可按 README 中的命令运行。它们用于验证输入、状态和数值行为；画面衔接、动作观感、真实指针交互及运行性能需要结合发布包的实际预览记录判断。
